# Guia de instalação Python

## Pré-requisitos
- Python instalado.
- Pip disponível no ambiente.

## Instalação
Instale as dependências do projeto:

```bash
python -m pip install -r requirements.txt
```

## Executando
Para executar um script Python:

```bash
python main.py
```

## Solução de problemas
Se o comando pip não funcionar, utilize:

```bash
python -m pip --version
```
